# 我的偏好(取值表 · 中性默认)

> **这份是出厂默认值,故意是中性的。** 它不代表任何人的审美,只保证生成出来的编排
> 「结构正确、不出错」——但它**不会**替你做风格决定。
>
> **风格是你自己长出来的,不是随包附赠的。** 用法:
>
> 1. 按默认值先排一期,导出成片;
> 2. 在 Overlay Studio 里按你自己的想法改(改落位、改密度、改颜色、删你不喜欢的卡);
> 3. 导出后对 AI 说一句 **「学一下」** —— 它会对比「AI 排的」和「你改完的」,
>    把出现两次以上的倾向问你确认,写进同目录的 `我的偏好.md` 和 `经验规则.md`;
> 4. 下一期就按你的取值排。三五期之后,这份表里的数字全是你的。
>
> **不要直接改这个文件**(升级会覆盖)。改动一律写进同目录 `我的偏好.md`,
> 同名条目覆盖这里 —— 和 `lint-rules.default.json` / `lint-rules.local.json` 一个道理。

## 密度与节奏

| 条目 | 默认值 | 说明 |
|---|---|---|
| 密度区间 | **8-12 张/分钟** | 中性起点。想更紧凑就往上调,想留白多就往下调 |
| 新动作间隔 | **2-4 秒** | 一个「新动作」= 新卡进场,或卡内下一条弹出 |
| 留白上限 | **不设** | 叙述过渡段可以什么都不放 |
| 短卡时长 | **3-5s** | 胶囊/药丸这类一句话的卡 |
| 内容卡时长 | **5-12s** | 跟着讲述时长走 |
| 常驻卡时长 | **跟整段/整章** | |
| 爆点卡 | **不设上下限** | 你自己判断哪里该炸 |
| 论点板陪跑 | **跟整段走** | 一个论点配一块板,板活多久由这段话讲多久决定 |

## 多样性

| 条目 | 默认值 | 说明 |
|---|---|---|
| 相邻两张卡不同 kind | **是** | 这条是防呆(防止连排两张一样的),不是审美 |
| kind 种类数下限 | **不设** | |
| 同种卡重复上限 | **不设** | |
| 同屏叠卡上限 | **2 张** | 超过 2 张容易糊;这是可读性下限,不是风格 |
| 同屏进场错开 | **≥0.5s** | 同时炸出会看不清,这是可读性下限 |

## 落位

| 条目 | 默认值 | 说明 |
|---|---|---|
| 主轴 | **不锁死** | 只要求避开画面中间的人物。要不要「所有卡都排左列」是你的风格选择 |
| position 分配 | **不预设** | 默认按卡片自身的建议落位;哪类内容固定放哪儿由你定 |
| 左列卡初始 offsetX | **0** | |
| 双列对照的右列 offsetX | **按画布宽度的 60% 起算** | 1920 画布约 1150,竖版自己换算 |

## 颜色

| 条目 | 默认值 | 说明 |
|---|---|---|
| 色义约定 | **不预设** | 「蓝=数据、红=否定」这类映射是一种设计约定,不是唯一正确答案。你可以自己定一套,写进 `我的偏好.md` |
| 一段一色 | **是** | 同段的卡 accent 一致。这条是「整体感」的最低要求,不是具体色号 |
| 整期主色 | **由你定** | 生成前问一次;不方便问就整期用同一个 accent |

## 文字量

| 条目 | 默认值 | 说明 |
|---|---|---|
| 卡面文字 | **必须短于口播原句** | 硬约束:禁止把 SRT 原句整句搬上卡。**具体几个字由你定** |
| 胶囊/条目字数上限 | **不设** | |
| 标题字数上限 | **不设** | |
| 文字类卡占比 | **不设** | |
| 英文小标签 | **可选** | 要不要配英文小标签、用什么字体风格,是风格选择 |

## 常驻层

| 条目 | 默认值 | 说明 |
|---|---|---|
| `chapter-bar` 章节条 | **可选** | 长视频(>3 分钟)建议配 |
| `caption-track` 字幕层 | **可选** | ⚠️ 原片已有烧录字幕时**不要**配,会重复 |
| 章节数 | **按内容定** | |

> 「画面每一帧都得有常驻层兜着」是一种画面观,不是通用规则。
> 默认不强制,你觉得空就自己加。

## 不受本表影响的(改这些会出错,不是风格问题)

这些是工程硬约束,写在 `SKILL.md` 里,**不要写进偏好表**:

- 输出格式(`version`/`theme`/`cards`/`id`/`kind`/`start`/`end`/`params`)
- `kind` 只能用卡片库里存在的,不许发明
- `start`/`end` 必须来自 SRT 的真实时间,不许自己编
- 卡内节奏参数(`holdMs`/`stepMs`/…)必须用 SRT 实际时长推算
- 「先分段脚本,再配卡」这个两步流程
- 标注「独占全屏」的卡不与其他卡同屏
- `lintOff` 字段一律原样保留
- 没有出处的截图不算证据
