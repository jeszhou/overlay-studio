# 使用指南 · 一条口播视频从素材到成片

```
你的口播视频
  → 导出 SRT 字幕
  → 让 AI 生成动效编排(overlay JSON)
  → 在编辑台里预览、微调
  → 导出透明动效层(MOV)
  → 剪辑软件里盖在原片上,完成
```

整个过程里,**只有第 2 步用到 AI**。之后所有修改都在编辑台上做,不再消耗任何额度。

---

## 第 0 步 · 准备(只做一次)

需要 [Node.js](https://nodejs.org/) ≥ 22.12 和 [ffmpeg](https://ffmpeg.org/)(导出时用,macOS 可 `brew install ffmpeg`)。

```bash
npm install
npm run dev
```

打开 `http://localhost:5177`。以后可以直接双击 `启动 Overlay Studio.command`(Windows 用 `start-overlay-studio.bat`)。

**先点顶栏「🎬 示例」** —— 会载入一套 28 秒的演示编排,不需要任何素材,按空格就能播。随便点一张卡改改右边的参数,几分钟就能明白这个工具怎么回事。

---

## 第 1 步 · 拿到口播视频和 SRT 字幕

- 正常录你的口播视频,**人在画面中间**,两侧留白给动效
- 用剪映「识别字幕」导出 SRT,或用 Whisper 等工具转写

**视频编码要用 H.264。** 浏览器解不了 HEVC(H.265),导入会黑屏。剪映导出时选「兼容性(H.264)」;已有的文件可以转一份:

```bash
ffmpeg -i 原视频.mp4 -c:v h264_videotoolbox -b:v 8000k -c:a aac 预览版.mp4
```

---

## 第 2 步 · 让 AI 生成动效编排

仓库内置了编排 skill(`.claude/skills/overlay-fx-generator/`),在仓库目录打开 Claude Code(或 Codex)即可使用。

把 SRT 丢给它,说 **「特效生成，这是我这期的 SRT」**,可以补一句这期是亮调还是暗调画面。

它会做三件事:读字幕 → 按语义分段 → 每段选卡并排好时间,输出一份 `xxx-overlay.json`。

**它不会现场发挥,只从做好的 20 张卡里挑。** 这也是为什么结果稳定、可预期。

想改 AI 的选卡偏好,直接改 `SKILL.md` 里的规则。

---

## 第 3 步 · 在编辑台里调

点「📥 导入 JSON」载入编排,再「换视频」导入你的口播视频,就能对着真实画面预览。

### 界面

| 位置 | 是什么 |
|---|---|
| 左栏 | 全局设置:整体底色(暗/亮)、特效整体大小、动画速度(字体在顶栏的 ⚙ 里) |
| 中间 | 实时预览 + 底部时间轴,彩色条就是每张卡的出场区间 |
| 右栏 | 选中卡片的全部参数:出现/消失时刻、内容文字、配色、位置、大小 |
| 左下角 | 编排体检浮窗,提示占位文案没换、时间越界、快闪等问题 |

### 常用调整

- **改内容**:右栏「内容」区,每个输入框上方都写着这个位置该填什么
- **挪位置 / 改大小**:直接在预览里拖动、缩放,或用右栏的微调滑杆
- **换配色**:右栏「强调色」;想整期换一个色调,改左栏的全局设置
- **改时间**:右栏顶部「出现 → 消失(秒)」,或直接拖时间轴上的色条
- **删除某张卡**:在时间轴上选中它,按 Delete

### 两条建议全程开着的层

- **chapter-bar 章节进度条**:顶部常驻,标出这期分几节、现在讲到哪
- **caption-track 字幕层**:双语字幕。如果你的成片已经烧录了字幕,就别开,会打架

它们让画面「没有一帧是没人管的」,是整体感的来源。

### 卡片怎么选

效果库按用途分了组,选卡时按「这一句在做什么」来找:

| 这一句在做什么 | 用哪一组 |
|---|---|
| 抛出论点、讲道理，要越讲越厚 | **常驻层**里的要点钉板(`pin-board`)——讲过的要点逐条钉在角落,整段不撤 |
| 摆事实、给证据 | **证据实证**:数字实证(`stat-proof`),巨号滚动计数给论点背书 |
| 强调一个数字 | **数据指标**:翻牌计数器(`odometer`)、指标环(`ring-metric`)、增长曲线(`growth-curve`)、数据排名条(`rank-bars`) |
| 前后对比 / 两条路线 | **对比取舍**:VS 对比卡(`versus-card`) |
| 一句金句要定格 | **金句观点**:金句药丸(`punch-pill`)、金句定格卡(`quote-lockup`);**文字进场**:模糊浮现(`blur-text`)、排版流(`type-shift`) |
| 讲人物或机构 | **人物锚定**:实体名牌(`entity-chips`) |
| 分段、转场 | **常驻层**的章节导航条(`chapter-bar`)从头到尾在场,讲到哪一段就推进到哪一格;开场想重一点,用排版流(`type-shift`)立题 |
| 演示软件操作 | **场景 · 运镜**:人物聚焦运镜(`focus-card`);**教程标注**:界面标注(`ui-callout`);讲命令行用 **场景 · B-roll** 的 3D 终端(`terminal-3d`) |
| 讲流程步骤 | **步骤流程**:竖排章节卡(`step-timeline`)、步骤打勾(`checklist`) |

一个原则:**一个论点养一块板,别撒一把卡。** 厚度感来自信息累积,不来自卡的数量。

## 第 4 步 · 导出透明动效层

点左栏「⬇ 导出整条时间轴(透明)」,成品在 `exports/output/`。

导出的是**带透明通道的 MOV**(ProRes 4444),只有动效,没有你的原片——所以原片一帧都不会被重新压缩。

### 运镜卡需要额外传一次口播视频

`focus-card` 这类卡会把你的画面「推近/缩到一角」,导出时需要真实画面参与渲染:

- **推荐做法**:左栏「🎥 传口播(一次全局用)」,传一份完整的 H.264 口播,所有运镜卡自动按时间轴对准各自的片段,不用剪、不用逐卡上传
- 单张卡右栏另传的以单卡为准

> 为什么必须传:预览里导入的视频只存在于你当前浏览器,导出时是另一个无头浏览器,读不到。

导出会同时生成一份音效清单 txt,记录哪个时刻配了什么音效。

---

## 第 5 步 · 剪辑软件里合成

- **剪映 / Final Cut**:把 `.mov` 拖到口播轨道**上方**,对齐第 0 帧,完事
- **Premiere**:导入 `.mov` 叠在 V2 轨

因为动效的时间轴和 SRT 完全一致,**只需要对齐一次(都从 0 开始)**,不用逐卡对时间。

---

## 编排体检(lint)

编辑台左下角会实时提示问题,也可以在命令行跑:

```bash
npm run -s lint:overlay -- path/to/overlay.json --duration 261
```

- **硬伤**(占位文案没换、时间超出视频长度)会报 error
- **建议**(快闪、大段空白、卡片叠太多)报 warn,不同意就忽略

阈值写在 `lint-rules.default.json`。想改成自己的标准,新建一份 `lint-rules.local.json` 覆盖(这个文件不进 git)。

某张卡上写 `"lintOff": ["规则名"]` 表示「我知道，我就要这样」——**检查器永远只报告，不改你的东西**。

---

## 让它越用越懂你(可选)

每次导出时,编辑台会把「AI 初选的版本」和「你调完的版本」一起存进 `exports/review-logs/`。

对 Claude Code 说 **「学一下」**,它会对比两版差异,和你逐条确认哪些是「以后都这样」的偏好,写进 skill 的经验规则里。之后每次生成编排,都会自动带上这些偏好。

用得越多,需要手动改的地方越少。

## 其他功能

### 音效
导出时每张卡会在自己出现的时刻自动配一个音效,直接混进 MOV 音轨,拖进剪辑软件就带声。每张卡右栏「节奏」组可以指定音效或关掉。

**仓库不附带音效文件**,自己下载几个 mp3 放进 `public/sfx/` 即可(见该目录 README);不放也能用,找不到就自动跳过。

整条音效轨建议在剪辑软件里统一压低 -12 ~ -18dB,别盖住人声。


### 讲过变浅
选中卡片,填「讲过变浅时刻」——到那一秒整张卡压暗到 45% 让位,但不消失,换段才退场。JSON 里对应 `dimAt`,AI 编排会自动填。

这是让画面「有层次而不拥挤」的关键:讲过的不撤场,只是退到背景。

### 证据可以是视频
`focus-card` 的图槽也能传 mp4,在小窗里循环播放,导出时逐帧对位。录屏、B-roll 都能当作会动的证据。

### 导出进度
点导出后右下角会显示渲染到第几帧、预计还需多久,导完弹系统通知。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 导入视频黑屏 | 视频是 HEVC 编码,转成 H.264(见第 1 步) |
| 卡片挡住人脸 | 拖动卡片避开,或在剪辑软件里用智能抠像把人物叠回最上层 |
| 画面是亮调,卡是暗色 | 左栏切「亮底」,或逐卡在右栏改主题 |
| 导出失败 | 检查磁盘空间(逐帧渲染很占地方)和 ffmpeg 是否装了 |
| 想清理占用 | `exports/` 里的旧文件夹可以直接删 |
