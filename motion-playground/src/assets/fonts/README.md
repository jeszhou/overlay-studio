# 字体

**仓库不附带字体文件。** 中文字体的授权条款各不相同,很多标着「免费商用」的字体
并不允许「随软件再分发」——两者不是一回事。所以请自己下载后放进这个文件夹。

## 怎么加

把 `.ttf` / `.otf` / `.woff` / `.woff2` 丢进这个文件夹就行,**字体名 = 文件名**(去掉扩展名),
Studio 左栏「全局字体」下拉里会自动出现。选中的字体存进编排 JSON,导出成片同步生效。

**同一家族有多个字重时**,文件名写成「家族名-字重数字」:

```
思源黑体-400.otf
思源黑体-700.otf
思源黑体-900.otf
```

会合并成一个下拉项「思源黑体」,各字重按真实字形渲染。不这么命名的话,浏览器只能拿
唯一那个字重去「伪粗」,大标题会糊成一团——干净的重黑体效果,靠的是真字重而不是伪粗。

## 去哪找

中文免费商用字体(下载前请自行确认最新条款):

- [思源黑体](https://github.com/adobe-fonts/source-han-sans) —— SIL OFL 开源许可,可自由使用和再分发
- [站酷字体系列](https://www.zcool.com.cn/special/zcoolfonts/)
- [阿里巴巴普惠体](https://www.alibabafonts.com/)
- 各字体作者的官方发布渠道

英文字体可以用 [Google Fonts](https://fonts.google.com/)(基本都是 OFL 许可)。

## 不放也能用

这个文件夹为空不影响运行,只是「全局字体」下拉里没有自定义选项,
所有文字用系统默认字体渲染。想要更好的效果随时再加。
