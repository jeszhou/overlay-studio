v1.3.0-rc.1 release candidate

View candidate PR Download a published release

What changed

  • Save, recover, and reopen projects. Existing arrangements remain editable.
  • Export a single card or the full timeline to transparent MOV and WebM, with progress, cancellation, and retry.
  • Build distribution packages from a specific Git commit. The Windows launcher installs dependencies from the lockfile.

Windows verification

The source ZIP was installed on a fresh setup in a Windows 11 ARM64 virtual machine. Installation used a verified dependency cache. Both export jobs ran in the default rendering mode. All four output files were decoded to verify transparency and audio.
