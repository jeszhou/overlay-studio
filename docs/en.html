Ask AI to install it

Open the full repository in an AI tool that can run your local terminal. If you have not downloaded it yet, open the parent folder where you want to install it, then share this prompt.

Install and launch the free edition of Overlay Studio on this computer. Prefer the source already in the current folder.
If the source is missing, get it from https://github.com/jeszhou/overlay-studio and place it in a new folder.
Check Node.js (22.12 or later), npm, FFmpeg, and ffprobe. Use official installation methods for missing tools.
In motion-playground, run npm ci using package-lock.json, then run npm run dev.
Verify that http://localhost:5177 opens and keep the server running. Tell me the install path, how to restart it, and how to open the demo and export a transparent MOV.

Install manually

In GitHub Releases, choose Source code (zip) under Assets and extract it, or clone with Git. Install Node.js 22.12 or later. Export also requires FFmpeg and ffprobe.

Download source ZIPDownload Node.js

Windows

Install FFmpeg in PowerShell and reopen the terminal. Open motion-playground and double-click start-overlay-studio.bat to install and launch.

winget install --id Gyan.FFmpeg -e
macOS

Install FFmpeg with Homebrew, then open motion-playground in the source folder.

brew install ffmpeg
npm ci
npm run dev

Open the editor

Keep the terminal running. Open localhost:5177, select 示例 (Demo), play the sample, and choose 导出透明 MOV (Export transparent MOV).

Create overlays from your subtitles

  1. Export SRT

    Export your timestamped subtitles from your video editor.

  2. Arrange with AI

    Give your AI tool the full repo and SRT. The bundled overlay-fx-generator Skill produces an overlay JSON.

  3. Edit and export

    Import the JSON and footage, refine the cards, and layer the transparent MOV or WebM over your video.
