让 AI 帮你安装

在能操作本机终端的 AI 工具里打开整个仓库根目录。还没下载时，打开准备存放项目的目录，再发送这段指令。

请在这台电脑上安装并启动 Overlay Studio 免费版。优先使用当前目录已有的源码。
如果还没下载，请从 https://github.com/jeszhou/overlay-studio 获取源码并放进新目录。
检查 Node.js（至少 22.12）、npm、FFmpeg 和 ffprobe；缺什么就用本机适用的官方安装方式。
进入 motion-playground，按 package-lock.json 执行 npm ci，然后运行 npm run dev。
确认 http://localhost:5177 能打开并保持服务运行。告诉我装在哪、怎么重启，以及如何点「示例」导出透明 MOV。

手动安装

在 GitHub Releases 的 Assets 下下载 Source code (zip) 并解压，也可以用 Git 克隆。安装 Node.js 22.12 或更高版本。导出还需要 FFmpeg 和 ffprobe。

下载源码 ZIP下载 Node.js

Windows

在 PowerShell 安装 FFmpeg 后重开终端。打开源码里的 motion-playground，双击 start-overlay-studio.bat 即可安装并启动。

winget install --id Gyan.FFmpeg -e
macOS

使用 Homebrew 安装 FFmpeg，再进入源码里的 motion-playground。

brew install ffmpeg
npm ci
npm run dev

完整安装指南

打开编辑台

保持终端运行。在浏览器打开 localhost:5177，点击「示例」，播放内置编排，再点「导出透明 MOV」。

localhost:5177

用自己的字幕做动效

  1. 导出 SRT

    在剪辑软件导出带时间码的字幕。

  2. 让 AI 编排

    把整个仓库和 SRT 交给 AI，使用内置 overlay-fx-generator Skill 生成编排 JSON。

  3. 编辑并导出

    导入 JSON 和视频，调整卡片。导出透明 MOV 或 WebM，叠到原片上。
